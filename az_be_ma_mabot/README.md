# بات تلگرام زرپایش

بات فارسی [@az_be_ma_mabot](https://t.me/az_be_ma_mabot)، اجراشده روی Telegram Serverless با دیتابیس SQLite خود پلتفرم؛ متصل به `https://zarpayesh-five.vercel.app/api/market`.

## استفاده

بات را به گروه اضافه و مدیر کنید تا بررسی دسترسی مدیران قابل اتکا باشد. با `/settings` پنل دکمه‌ای و با `/help` راهنمای کامل را باز کنید. فقط مدیران می‌توانند برنامه‌ها، هشدارها و تنظیمات گروه را تغییر دهند. کاربران عادی می‌توانند قیمت بگیرند؛ محدودیت درخواست مشترک هر گفتگو ۱۰ ثانیه است.

```text
/schedule usd 60 on 24
/schedule eur 120 off
/daily geram18 09:00 on 168
/chart usd off
/price usd chart 24
/unit toman
/quiet 23:00 08:00
/silent on
/alert usd above 100000
/pause
/resume
```

برنامهٔ اول هر ساعت دلار را با تصویر نمودار ۲۴ساعته می‌فرستد؛ برنامهٔ دوم یورو را هر دو ساعت بدون تصویر می‌فرستد. هر نماد یک برنامه در هر گروه دارد؛ ثبت دوباره آن را ویرایش می‌کند. بازهٔ ارسال ۵ تا ۱۰۰۸۰ دقیقه، نمودار ۱ تا ۱۶۸ ساعت، حداکثر برنامه‌ها ۲۰ و هشدارها ۳۰ است. آستانهٔ هشدار با واحد فعلی گفتگو تفسیر و با واحد پایه ذخیره می‌شود؛ تغییر واحد بعدی آستانه را عوض نمی‌کند. انس جهانی همیشه دلار است.

تمام ساعت‌ها تهران (UTC+03:30) هستند. ساعات سکوت و توقف روی ارسال خودکار و هشدارها اثر دارند؛ استعلام دستی همچنان کار می‌کند. هشدار یک‌باره است و پس از ارسال موفق حذف می‌شود. هنگام خروج/اخراج بات، تنظیمات آن گروه پاک می‌شود. پس از تبدیل گروه به سوپرگروه تنظیم مجدد لازم است.

## زمان‌بندی واقعی

SDK نسخهٔ ۰.۲ زمان‌بند داخلی مستندشده ندارد. فایل `../.github/workflows/telegram-bot.yml` تقریباً هر پنج دقیقه ماژول `endpoints/dispatch` را با **CLI دارای دسترسی مدیریت** در TG Cloud اجرا می‌کند. بات، تاریخچه، بررسی برنامه‌ها و ارسال پیام همگی روی TG Cloud اجرا می‌شوند؛ GitHub فقط محرک دوره‌ای است. کامپیوتر شخصی نباید روشن بماند.

پس از ادغام شاخه در `main`، در GitHub → Settings → Secrets and variables → Actions، یک repository secret با نام `TGCLOUD_TOKEN` و مقدار CLI Access Token بات ذخیره کنید. توکن Bot API با این توکن متفاوت است. مقدار توکن را هرگز در فایل workflow، کد، issue یا log ننویسید. سپس Actions → Telegram bot → Run workflow را یک بار اجرا کنید. `deploy` فقط برای استقرار مجدد لازم است.

GitHub اجرای دقیق سر ساعت را تضمین نمی‌کند؛ کران ممکن است چند دقیقه دیر اجرا شود. هیچ تاریخچهٔ عقب‌افتاده‌ای به صورت رگبار ارسال نمی‌شود. در مخزن عمومیِ بدون فعالیت، GitHub ممکن است scheduled workflow را پس از ۶۰ روز غیرفعال کند؛ وضعیت Actions را پایش کنید. برای تضمین دقیقه‌ای و تعداد زیاد گروه‌ها، محرک باید به یک زمان‌بند با SLA منتقل شود. هر invocation حداکثر ۲۰ برنامه و ۳۰ هشدار بررسی می‌کند؛ مقیاس بالاتر نیازمند صف/چند batch است.

## صحت داده و نمودار

تغییر همراه در `src/lib/rates.ts` کیفیت هر قیمت را با `dataQuality` و زمان مشاهده را با `observedAt` مشخص می‌کند. بات فقط `live` با قیمت عددی مثبت و مشاهدهٔ حداکثر سه دقیقه قبل را می‌پذیرد. داده‌های نمونه، نرخ‌های تخمینی و fallback هرگز اعلام نمی‌شوند. timestamp زمان **دریافت از منبع** است و ممکن است خود بازار بسته باشد؛ ساعت اعلام‌شدهٔ منبع در پیام جداگانه می‌آید.

نمودار PNG از نمونه‌های واقعی ذخیره‌شده در بازه‌های پنج‌دقیقه‌ای ساخته می‌شود؛ sparklineهای ثابت سایت مصرف نمی‌شوند. تاریخچه هفت روز نگه داشته می‌شود. در شروع، تا ثبت دو نمونه پیام متنی با توضیح کمبود تاریخچه ارسال می‌شود. تصویر داخل V8 ساخته می‌شود و هیچ داده‌ای به سرویس نمودار بیرونی نمی‌رود.

در قطعی API هیچ نرخ ساختگی ارسال نمی‌شود و workflow خطا می‌دهد. قفل SQLite مانع اجرای هم‌زمان زمان‌بند می‌شود. برای خطای ۴۲۹ و خطاهای انتقال، retry با فاصله انجام می‌شود. با وجود قفل، تحویل دقیقاً یک‌باره در شکست بین پذیرش پیام در تلگرام و ثبت موفقیت در DB تضمین‌شدنی نیست؛ آن حالت ممکن است یک پیام تکراری ایجاد کند. توکن CLI قدرت مدیریت کل بات را دارد؛ دسترسی نوشتن به مخزن را محدود نگه دارید.

## توسعه و استقرار

Node.js 24 و npm:

```sh
cd az_be_ma_mabot
npm ci
npm run check
npm test
npx tgcloud login
npm run deploy
npx tgcloud migrate --safe
npx tgcloud run endpoints/operator '{action:"register"}' --ctx '{operator:true}'
npm run tick
npx tgcloud webhook
```

توکن به روش استاندارد CLI در `.tgcloud/` نگه داشته می‌شود یا در محیط CI از `TGCLOUD_TOKEN` خوانده می‌شود؛ `.tgcloud/` و `node_modules/` در git نیستند. `endpoints/dispatch` و `endpoints/operator` از HTTP Mini App قابل استفاده نیستند: marker کنترل‌شدهٔ context را فقط مسیر مدیریت CLI می‌تواند تعیین کند؛ فرستادن marker داخل body یا `initData` مجوز نمی‌دهد.

تست‌ها از SQLite واقعی محلی و شبیه‌ساز API تلگرام استفاده می‌کنند؛ پیام واقعی به گروهی ارسال نمی‌کنند. برای smoke test محیط واقعی از `endpoints/operator` استفاده کنید. آدرس منبع و نام نمادها در `tgcloud/lib/config.js` قرار دارند.

مرجع اصلی: https://core.telegram.org/bots/serverless
