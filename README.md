# زرپایش

پایش فارسی ارز، طلا و سکه با Next.js 15 و دادهٔ عمومی TGJU. سایت: [zarpayesh-five.vercel.app](https://zarpayesh-five.vercel.app). بات: [@az_be_ma_mabot](https://t.me/az_be_ma_mabot).

## امکانات

- نرخ‌های بازار آزاد با تفکیک زمان دریافت و ساعت اعلام‌شدهٔ منبع، جستجو و فیلتر منطقه.
- تاریخچهٔ واقعی داخل روز و روزانه، نمودار خطی و شمعی، بازه‌های یک ساعت تا یک سال، بررسی هر نمونه با لمس، ماوس یا صفحه‌کلید.
- مبدل دارایی‌ها و ریال/تومان با ورودی اعداد فارسی و عربی؛ قیمت دلاری انس جهانی با نرخ دلار به ریال تبدیل می‌شود.
- برآورد فاکتور طلا با درصدهای ورودی کاربر و حباب برآوردی سکه.
- هشدار یک‌بارهٔ قیمت در localStorage، اعلان داخل صفحه و صدای اختیاری؛ فقط هنگام باز بودن سایت.
- فونت متغیر فارسی Vazirmatn به صورت محلی با مجوز OFL، ارقام هم‌عرض، رابط واکنش‌گرا، فوکوس صفحه‌کلید و پشتیبانی کاهش حرکت.
- بات TG Cloud با کیبورد پیوی، تنظیمات مستقل گروه‌ها، اعلام دوره‌ای و روزانه، نمودار واقعی، ساعات سکوت و هشدار قیمت. [راهنمای بات](az_be_ma_mabot/README.md).

## APIها و صحت داده

`GET /api/market` قیمت‌ها را از جدول عمومی TGJU دریافت می‌کند. `dataQuality` کیفیت داده و `observedAt` زمان دریافت است؛ زمان آخرین نرخ در `updatedAt` می‌آید. دادهٔ موقت کش ممکن است نمایش داده شود، اما دادهٔ نمونه و نرخ تخمینی در رابط نمایش داده نمی‌شود. انس جهانی بر حسب دلار و سایر قیمت‌ها در API بر حسب ریال هستند. نرخ دینار عراق به ازای یک دینار است.

`GET /api/history?symbol=price_dollar_rl&range=1D` تاریخچهٔ داخل روز را از آرایهٔ عمومی نمودار صفحهٔ نماد می‌خواند. بازه‌های `1W`, `1M`, `3M`, `6M`, `1Y` از جدول تاریخچهٔ روزانه می‌آیند. داده‌ها مرتب، تکرارها حذف و نقاط نامعتبر یا آینده کنار گذاشته می‌شوند. نمودار شمعی از OHLC روزانه یا تجمیع باز/بسته/سقف/کف نمونه‌های واقعی ساخته می‌شود؛ هیچ نوسان مصنوعی تولید نمی‌شود. نبود داده در بازهٔ کوتاه با پیام مشخص نمایش داده می‌شود. تاریخچه ممکن است به دلیل بسته بودن بازار یا تأخیر منبع به روز آخر معاملات محدود باشد.

نرخ سنا/نیما، شاخص ترس و طمع، آمار حجم و تحلیل‌های خبری بدون منبع نمایش داده نمی‌شوند. برآورد مبدل و فاکتور شامل کارمزد معامله نیست و نرخ قانونی مالیات یا سود را فرض نمی‌کند؛ درصدها را مطابق فاکتور وارد کنید.

## استقرار

مخزن به پروژهٔ Vercel با نام `zarpayesh` متصل است؛ تغییرات `main` نسخهٔ اصلی را منتشر می‌کند. Workflow بات بعد از دریافت وضعیت TG Cloud، ماژول‌ها را منتشر و migrationهای افزایشی را اعمال می‌کند؛ محرک پنج‌دقیقه‌ای GitHub مستقل از روشن بودن رایانه اجرا می‌شود. `TGCLOUD_TOKEN` فقط باید در Actions Secret باشد. فایل‌های `.env*` و `.tgcloud/` در Git قرار نمی‌گیرند.
