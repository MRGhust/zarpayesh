# 🌟 زرپایش (ZarPayesh) — سامانه هوشمند مانیتورینگ بلادرنگ طلا، ارز و مسکوکات

سامانه حرفه‌ای، بلادرنگ و فوق‌پیشرفته مانیتورینگ قیمت لحظه‌ای دلار، طلا، سکه و ارزهای خارجی مبتنی بر شبکه اطلاع‌رسانی طلا، فلزات و ارز (**TGJU.org**)، با بهره‌گیری از طراحی اختصاصی **Executive Slate & Frosted Bullion** و پشتیبانی بومی از زبان فارسی و چینش راست‌به‌چپ (RTL).

---

## ✨ امکانات کلیدی سامانه

### ۱. مظنه زنده اسکناس و نقدی ارزهای مرجع (Forex & Cash Rates)
- **پوشش ۱۲ ارز بین‌المللی:** دلار آمریکا (USD)، یورو (EUR)، درهم امارات (AED)، پوند انگلیس (GBP)، لیر ترکیه (TRY)، دلار کانادا (CAD)، فرانک سوئیس (CHF)، یوان چین (CNY)، دینار عراق (IQD)، منات آذربایجان (AZN)، روبل روسیه (RUB)، گریونا اوکراین (UAH).
- **تفکیک رژیم‌های قیمتی:** بازار آزاد فردوسی، سامانه سنا (اسکناس رسمی صرافی ملی) و سامانه نیما (حواله تجاری).
- **شاخص‌های کلان:** نوسان روزانه، حجم تخمینی معاملات توافقی و تحلیل گرافیکی شکاف آربیتراژ نیما / آزاد.
- **نمودارهای مینیاتوری (Sparklines):** نمایش روند ۷ روز اخیر هر ارز در قالب وکتور SVG بدون افت سرعت.

### ۲. بازار طلا، مسکوکات و حباب‌سنج هوشمند (Gold & Coins)
- **نرخ‌های پایه:** انس جهانی طلا (XAU/USD)، مظنه مثقال پایه ۱۷ عیار (تهران)، طلای ۱۸ عیار خام (۷۵۰) و طلای ۲۴ عیار شمش (۹۹۹).
- **ماتریس جامع حباب مسکوکات بانکی:** محاسبه بلادرنگ ارزش ذاتی بر اساس فرمول وزن و عیار قانونی، مبلغ اسمی حباب و درصد حباب برای:
  - سکه تمام طرح امامی (۱۳۸۶)
  - سکه بهار آزادی (طرح قدیم)
  - نیم سکه بهار آزادی
  - ربع سکه بهار آزادی
  - سکه گرمی بانک مرکزی
  - پلاک پارسیان ۱ گرمی
- **محاسبه‌گر رسمی فاکتور طلا و زیورآلات:** بر اساس فرمول مصوب اتحادیه طلا و جواهر (طلای خام + اجرت ساخت + سود ۷٪ + مالیات بر ارزش افزوده ۹٪ بر اجرت و سود).
- **بخش حقوقی و مقررات:** راهنمای قانون سود ۲٪ طلای دست‌دوم، نشان‌های ضرب قانونی و معافیت اصل طلا از مالیات.

### ۳. دیده‌بان، اتاق معاملات و دماسنج احساسات (Watchlist & Terminal)
- **نمودار مقایسه‌ای تعاملی:** مقایسه زنده طلای ۱۸ عیار با دلار آزاد با بازه‌های زمانی `1H`, `1D`, `1W`, `1M`, `1Y` و قابلیت تغییر حالت به کندل‌استیک (Candlestick) و خطی (Line).
- **دماسنج احساسات و طمع بازار (Fear & Greed Index):** نمایش وضعیت روانی معامله‌گران از ۰ (ترس شدید) تا ۱۰۰ (طمع شدید).
- **دیده‌بان سریع سفارشات (Order Book):** اسپرد قیمت خرید و فروش و زمان آخرین تراکنش.

### ۴. مبدل فوق‌پیشرفته ارز، مسکوکات و ریال (Multi-Currency Converter)
- **مبدل دوطرفه آنی:** با دکمه انیمیشنی معکوس‌سازی (Swap) و پشتیبانی از رژیم‌های آزاد، سنا و نیما.
- **سبد تبدیل چندارزی (Multi-Currency Basket):** تبدیل همزمان مقدار ورودی به تمام ارزها، مسکوکات و طلا در قالب جدول ماتریسی.
- **استعلام تاریخی قدرت خرید ریال:** محاسبه قدرت خرید سرمایه ریالی در ۱ ماه، ۶ ماه، ۱ سال، ۳ سال و ۵ سال گذشته و سنجش افت ارزش برابری پول ملی.

### ۵. قابلیت‌های سیستمی و تجربه کاربری (UX)
- **تغییر واحد سراسری (تومان / ریال):** تبدیل بلادرنگ تمامی مقادیر و لیبل‌های کل سامانه تنها با یک کلیک.
- **تیکر متحرک پیوسته (Running Marquee):** نوار قیمت‌های زنده در بالای سایت با امکان توقف روی هاور (`hover:pause`).
- **ثبت هشدار قیمت (Price Alerts):** تعیین سقف و کف هشدار برای ارزها و طلا با آلارم صوتی.
- **همگام‌سازی زنده (Live Sync):** پایش مداوم از API و به‌روزرسانی خودکار هر ۲۰ ثانیه بدون رفرش صفحه.

## 🛠 معماری فنی و فناوری‌ها

- **فریم‌ورک:** [Next.js 15 (App Router)](https://nextjs.org/)
- **زبان:** TypeScript
- **استایل‌دهی:** Tailwind CSS (با پالت رنگی اختصاصی *Executive Slate & Frosted Bullion*)
- **آیکون‌ها:** Lucide React و Material Symbols
- **فونت‌ها:** Vazirmatn، Plus Jakarta Sans و JetBrains Mono (با ارقام مونو اسپیس `tabular-nums` جهت جلوگیری از پرش چیدمان)
- **سرویس بک‌اند:** Next.js Route Handlers (`/api/market`) مجهز به کش در حافظه (In-Memory SWR Cache 30s) و تجمیع‌کننده ضد قطعی داده‌های **TGJU.org**.

## 🚀 راه‌اندازی و اجرای محلی (Local Development)

```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت بیلد پروداکشن
npm run build

# اجرای نسخه پروداکشن
npm run start
```

سپس مرورگر خود را باز کرده و به آدرس [http://localhost:3000](http://localhost:3000) مراجعه فرمایید.

## ☁️ استقرار در ورسل (Deploy to Vercel)

این پروژه با استاندارد کامل Next.js App Router طراحی شده و با استقرار بدون سرور در Vercel سازگاری ۱۰۰٪ دارد:

### روش اول: استقرار از طریق گیت‌هاب (پیشنهادی)
1. مخزن را به گیت‌هاب پوش کنید (`git push -u origin main`).
2. وارد پنل [Vercel](https://vercel.com) شوید.
3. دکمه **Add New Project** را بزنید و مخزن را انتخاب کنید.
4. بدون نیاز به هیچ تنظیم خاصی، روی **Deploy** کلیک کنید. پروژه ظرف کمتر از ۱ دقیقه مستقر می‌شود.

### روش دوم: استقرار از طریق ترمینال (Vercel CLI)
```bash
npx vercel
# یا برای استقرار مستقیم نسخه پروداکشن:
npx vercel --prod
```
